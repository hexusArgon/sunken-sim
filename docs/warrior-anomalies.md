# Warrior anomalies / gaps

- Berserker Rage (I08M): в симе пока не моделируется (self-DoT / Enraged Regen amplify) — DPS = bare.
- Slaughterhouse (I0O1): крит-бонус смоделирован грубо через rating; почти не двигает bare.
- Ignore Pain / Tenacity / Living Shield / Battle Scars / Hellscream / Thirst: defensive/heal, в DPS-таблице как IGNORED.
- Brutality: execute 25% ниже 40% HP (после фикса 0.25, не 25.0).
